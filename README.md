# Emoji Decoder 🔍

Have you ever seen a broken "square box" (□) emoji on Windows and wondered what it was? This simple Web App decodes those missing characters into their actual emoji images.

## Features
- **Zero Installation**: Runs entirely in the web browser.
- **Instant Decoding**: Just paste the broken emoji, and it reveals the image instantly.
- **Glassmorphism UI**: Beautiful, modern, and responsive design.

## How it works
1. Copy the broken emoji text (the square box) from any application.
2. Paste it into the input field on the website.
3. The app extracts the Unicode code points and fetches the corresponding high-resolution image from [Twemoji](https://github.com/twitter/twemoji).

## Deployment
This project is designed to be hosted on GitHub Pages. No backend or server is required.
